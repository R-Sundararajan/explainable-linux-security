# Local threat model

`security_threat_model_v1.joblib` is generated by
`tests/ml/train_models.sh` from the reproducible safe scenario corpus. Runtime
loading is allowed only after size, ownership, permissions, schema, class order,
feature order, and the configured SHA-256 digest are validated.

Joblib is a pickle-based format and must never be used here with an untrusted or
unpinned artifact. The model is local, performs no network access, and has no
action-execution capability.
