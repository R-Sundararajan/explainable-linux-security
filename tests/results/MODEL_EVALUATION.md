## Deterministic mapping and comparison

For evaluation only, `QUARANTINE` and `KILL_STOP` map to `MALICIOUS`; a `MONITOR` decision with any deterministic finding or anomaly-threshold crossing maps to `SUSPICIOUS`; otherwise `MONITOR` maps to `BENIGN`. This exposes a real limitation: the enforcement gate is intentionally action-oriented and cannot naturally express all three intent classes.

Deterministic rules remain authoritative for hard facts and the only possible `KILL_STOP` authorization. ML improves multi-signal classification where no hard combination exists, but cannot lower deterministic floors or signal a process directly.

On this holdout, deterministic assessment correctly kept both `benign_network` seeds benign where the selected Logistic model produced false-positive `SUSPICIOUS` labels. Logistic corrected both benign backup seeds, all four suspicious cases, and all four malicious cases relative to the deterministic intent mapping. No held-out case was misclassified by both systems. The ensemble classified all 12 correctly, but it was not substituted after opening the holdout because that would leak final-test information into model selection.

## Final architecture

```text
process_evidence_v1
        ↓
Temporal case builder → ml_features_v1 → Local ML threat model
        └──────────────────┬───────────────────────┘
                           + deterministic security gate
                                      ↓
                                Policy authority
                                      ↓
                       MONITOR / QUARANTINE / KILL_STOP
                                      ↓
                     Grounded behavioral + rule XAI
```

## Accuracy limitations

The selected model produced two false positives (both `benign_network` seeds), zero suspicious false negatives, and zero malicious false negatives in this holdout. The deterministic mapping missed all four suspicious and all four malicious intent labels, although it retained safe action floors. There were no cases missed by both in this closed corpus; novel real behavior remains unresolved by definition.

This is a small, balanced synthetic corpus from safe fixtures, not production prevalence. Seeds within a family are correlated even though families do not cross splits. The results do not establish universal malicious detection. Real-world drift, prevalence, novel behavior, and telemetry gaps require continued monitoring and independently sourced labeled cases.
